# AI Interview Prep — Frontend

React (Vite) + Tailwind CSS frontend for the AI Interview Preparation Platform.

See the [root README](../README.md) for full project setup, architecture, and deployment instructions.

## Quick Start

```bash
cp .env.example .env   # set VITE_API_BASE_URL if the backend isn't on localhost:5000
npm install
npm run dev              # http://localhost:5173
```
